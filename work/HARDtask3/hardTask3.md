Задача: «Клиентские предпочтения и финансовая активность (PostgreSQL)»

Для каждого клиента из таблицы customer необходимо определить:

любимую категорию фильмов — ту, в которой клиент совершил наибольшее количество аренд.
Если таких категорий несколько (равное количество аренд), выбирается лексикографически меньшая по названию.

общую сумму платежей клиента за все аренды, округлённую до двух знаков;

средний чек клиента, округлённый до двух знаков;

ранг клиента по общей сумме платежей среди всех клиентов (с пропусками, по убыванию).

В результат включаются только те клиенты, которые совершили более 10 аренд.

Отсортируйте результат по возрастанию ранга.

Формат вывода

+-------------+------------+------------+------------------+---------------------+----------------+------------+------------------+
| customer_id | first_name | last_name  | favorite_category| rentals_in_favorite | total_payments | avg_payment| rank_by_payments |

|           5 | ELIZABETH  | BROWN      | Sports           |                   8 |          91.77 |       3.53 |                1 |
|           7 | MARIA      | MILLER     | Sci-Fi           |                   7 |          89.85 |       3.99 |                2 |
|         ... |            |            |                  |                     |                |            |                  |
+-------------+------------+------------+------------------+---------------------+----------------+------------+------------------+
