Маркетинговая команда анализирует купоны, которые находятся в обращении, и проверяет их сроки действия и размеры скидок.

Из таблицы coupons выберите купоны, которые:

находятся в статусе ISSUED (Выдан) или USED (Использован)
крайний день действия (поле end_at) находится в диапазоне с 2025-01-01 по 2025-12-31
имеют номинал скидки (поле value) от 5 до 50 включительно
Для каждого купона выведите id, code, coupon_type, value, start_at, end_at, value_with_tax, code_len, label, где дополнительными полями являются

value_with_tax — значение скидки, увеличенное на 20% и округлённое до 2 знаков после запятой
code_len — длина кода купона
label — строка вида CODE (VALUE%)
Отсортируйте результат по сроку действия по возрастанию, затем по номиналу скидки по убыванию. Выведите первые 20 строк результата.
