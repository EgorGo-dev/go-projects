Чтобы быстро оценить ассортимент, удобно одной строкой увидеть ключевые показатели товарных позиций.

Для таблицы products выведите в одной строке: общее количество товаров, минимальную цену, максимальную цену, среднюю цену (округлить до 2 знаков), среднюю цену с налогом 20% (округлить до 2 знаков).

Округлять значения столбцов кроме двух последних не нужно.

Формат ввода
Для выполнения задач этого step'а необходимо воспользоваться тестовой сборкой базы данных grocery_test.sqlite.

Описание базы данных, схема связей, особенности хранения данных в таблице и ссылка на скачивание тестовой сборки базы данных можно найти в предыдущем шаге step 1 level 1 БД для практических задач "Продукты".

При выполнении практических заданий необходимо загрузить файл базы данных в любую удобную среду разработки (в курсе рассматривается SQLite) для написания SQL-запросов и работать с ней.

Отправленные запросы в этой и последующих задачах этого step'а будут тестироваться на промышленной сборке БД grocery.sqlite, которая является закрытой. Таким образом будет проверяться корректность выполнения запроса на различных данных в БД.
