Чтобы понять, где клиенты получают самые большие скидки, нужно посмотреть на позиции чеков и сравнить проценты скидок.

Для таблицы sale_items вычислите:

сумму без скидки,
итоговую сумму к оплате,
процент скидки, округлённый до целого значения.
Отсортируйте строки по проценту скидки по убыванию, затем по итоговой сумме по убыванию. Выведите строки с 21-й по 40-ю.

Примечания
Не забывайте, что над значениями столбцов в SQL можно выполнять арифметические операции (а также группировать их порядок круглыми скобками) - их результат вычисляется построчно для всей выборки.

Округление до целого значения, которое необходимо сделать в задаче, можно выполнить при помощи функции ROUND(<ваше арифметическое выражение в SQL>).
