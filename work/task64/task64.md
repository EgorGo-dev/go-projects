Посчитайте общую сумму продаж по категориям.

Выведите поля category_name и total_revenue (сумма продаж с учётом скидок, вычисляемая по формуле s u m ( u n i t _ p r i c e × q u a n t i t y − d i s c o u n t _ a m o u n t ) sum(unit\_price \times quantity - discount\_amount)sum(unit_price×quantity−discount_amount) для каждой позиции чека с округлением до 2-х знаков после запятой по математическим правилам).

Используйте данные из таблиц sale_items, products, categories.

Отсортируйте результат по полю total_revenue по убыванию.
