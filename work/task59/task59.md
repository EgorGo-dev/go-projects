задача из Яндекс LMS - Яндекс Лицея |SQL|

Для каждого города city по данным из таблицы stores определите:

количество активных магазинов (total_active_stores),
сколько из них совершали продажи (stores_with_sales) - т.е. количество таких магазинов, которые содержатся в сведениях о продажах в таблице sales,
долю работающих магазинов (activity_ratio).
Учитывайте только магазины со статусом is_active = 1.

Результат отсортируйте по убыванию доли активных магазинов.
