Чтобы использовать категории в отчётах и интерфейсе, часто создают короткий код категории и дополнительную текстовую метку на его основе.

Для таблицы categories выведите:

name — название категории;
name_len — длину названия категории;
short_code — первые 3 символа названия;
label — строку вида SHORT_CODE (LEN), где SHORT_CODE — первые 3 символа названия, LEN — длина названия категории.
Отсортируйте результат по name_len по убыванию, затем по name по возрастанию.
