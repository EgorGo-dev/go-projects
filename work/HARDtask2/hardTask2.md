Задача из Яндекс LMS - Яндекс Лицея |SQL|

Психологическое предупреждение: решение этой задачи при помощи подзапросов довольно большое. Поэтому эта задача в числе необязательных к решению.

Найдите продажи по таблице sales, которые являются самыми дорогими покупками для каждого клиента.

Выведите запросом следующие поля:

id — идентификатор продажи;
customer_id;
sale_total — сумма чека вычисляемая старой доброй формулой 
sum(unit_price × quantity − discount_amount) с округлением в 2 знака после запятой.
