Для каждого города определите рейтинг клиентов по суммарной выручке.

Выведите запросом следующие поля:

city — город магазина;
customer_id — идентификатор клиента;
total_revenue — общая сумма его покупок с округлением до 2-х знаков;
city_rank — место клиента в рейтинге города.
При решении задачи используйте оконные функции ранжирования.

Рейтинг по городам строится по убыванию общей выручки с продаж каждого клиента.

Формат ввода
Для выполнения задач этого step'а необходимо воспользоваться тестовой сборкой базы данных grocery_test.sqlite.

Описание базы данных, схема связей, особенности хранения данных в таблице и ссылка на скачивание тестовой сборки базы данных можно найти в шаге step 1 level 1 БД для практических задач "Продукты".

При выполнении практических заданий необходимо загрузить файл базы данных в любую удобную среду разработки (в курсе рассматривается SQLite) для написания SQL-запросов и работать с ней.

Отправленные запросы в этой и последующих задачах этого step'а будут тестироваться на промышленной сборке БД grocery.sqlite, которая является закрытой. Таким образом будет проверяться корректность выполнения запроса на различных данных в БД.
