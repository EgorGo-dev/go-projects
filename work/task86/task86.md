Необходимо оценить уровень вовлечённости клиентов. Подготовьте список клиентов с количеством совершённых ими аренд.

В результате должны быть поля:

customer_id — идентификатор клиента;
rentals_count — количество аренд, совершённых этим клиентом.
Дополнительно требуется вычислить среднее количество аренд на одного клиента по всей базе данных (отдельным запросом).

Формат вывода
В данной задаче необходимо сдать на проверку сразу два SQL-запроса. В консоли исполнения результат каждого из них в текстовом формате представляет собой две таблицы, собранной по SELECT'ам, выведенные друг под другом. В случае, если оба запроса корректны, задача будет зачтена. В случае, если один из запросов будет не совпадать по выводу с эталоном, задача считается нерешённой.

Пример формата вывода требуемого запроса (тестирующая система преобразует вывод запроса в формат TABLE):

+-------------+---------------+
| customer_id | rentals_count |
+-------------+---------------+
| 1           | 32            |
| 2           | 27            |
| 3           | 26            |
| 4           | 22            |
| 5           | 38            |
| 6           | 28            |
| 7           | 33            |
... (строки результата первого SELECT'а)
+-------------------------+
|         AVG(cnt)        |
+-------------------------+
| <вещественное значение> |
+-------------------------+
(табличка, относящаяся ко второму SELECT'у)
