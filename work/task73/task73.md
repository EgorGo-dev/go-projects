задача из Яндекс LMS - Яндекс Лицея |SQL|

Для каждого товара выведите:

product_name — название товара;

category_id — его категорию;

base_price — базовую цену;

price_rank_in_category — номер товара по убыванию цены внутри категории, относящейся к этому товару (учитывать непосредственно объявленую категорию товару, а не родительские категории).
Отсортируйте полученный результат по полю category_id, затем по полю price_rank_in_category.
