задача из Яндекс LMS - Яндекс Лицея |SQL|

Для каждого аккаунта account_id по данным из таблицы loyalty_point_transactions выведите:

количество операций (tx_count),
сумму всех изменений (total_delta),
и оставьте только активные аккаунты (⩾3 операции).

Отсортируйте полученный результат по суммарному изменению баллов по убыванию (total_delta).

Формат вывода
Корректный вывод для тестовой сборки (тестирующая система преобразует вывод запроса в формат CSV):

account_id,tx_count,total_delta
88,4,86
67,4,68
133,3,42
68,4,42
143,6,1
Примечания
В дополнение к взывающему названию задачи уточним, что при решении вам понадобится оператор HAVING COUNT(*).
