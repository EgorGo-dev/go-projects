Для каждого магазина необходимо определить рейтинг продаж по сумме чека.

Выведите следующие поля:

store_id;
sale_id;
sale_amount — сумма продажи по всем позициям с округлением до 2-х знаков;
rank_in_store — место продажи по убыванию суммы внутри магазина.
Если суммы совпадают — место должно совпадать.

Отсортируйте полученный результат по полю store_id, затем по полю rank_in_store.

Формат ввода
Для выполнения задач этого step'а необходимо воспользоваться тестовой сборкой базы данных grocery_test.sqlite.

Описание базы данных, схема связей, особенности хранения данных в таблице и ссылка на скачивание тестовой сборки базы данных можно найти в шаге step 1 level 1 БД для практических задач "Продукты".

При выполнении практических заданий необходимо загрузить файл базы данных в любую удобную среду разработки (в курсе рассматривается SQLite) для написания SQL-запросов и работать с ней.

Отправленные запросы в этой и последующих задачах этого step'а будут тестироваться на промышленной сборке БД grocery.sqlite, которая является закрытой. Таким образом будет проверяться корректность выполнения запроса на различных данных в БД.

Примечания
При вычислении поля days_to_next_purchase вам может понадобиться полезная функция SQLite JULIANDAY(...), которая преобразует текстовое значение даты в нужный объект, по которому можно найти разницу дат (JULIANDAY(date_1) - JULIANDAY(date_2)). В эту функцию можно оборачивать как значения столбцов (передавая имя поля), так и агрегатные/оконные функции. Подробнее о работе с ней можно почитать по ссылке.
