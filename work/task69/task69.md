задача из Яндекс LMS - Яндекс Лицея |SQL|

Для каждого аккаунта лояльности сравните текущий баланс баллов и сумму всех транзакций по этому аккаунту.

Выведите запросом следующие поля:

account_id — идентификатор аккаунта;

points_balance — баланс (из таблицы loyalty_accounts);

tx_sum — сумма всех points_delta;

difference - разница между балансом и суммой транзакции.
