задача из Яндекс LMS - Яндекс Лицея |SQL|

Для каждой продажи выведите:

customer_id - идентификатор покупателя;

sale_id - идентификатор продажи;

sale_amount - сумму продажи по всем позициям (вычисляемую по формуле из первой задачи);

customer_total_amount — общий оборот клиента (сумма всех продаж по всем позициям);

sale_share_percent — доля текущей продажи в обороте клиента (в процентах, округлённых до сотых).

Отсортируйте полученный результат по полю customer_id, затем по полю sale_amount по убыванию.
