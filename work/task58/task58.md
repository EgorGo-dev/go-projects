задача из Яндекс LMS - Яндекс Лицея |SQL|

Для каждого магазина store_id по данным из таблицы sales выведите:

число чеков (sales_count)
число уникальных клиентов (customers_count)
статус магазина в зависимости от их количества (store_level):

Low(⩽20),Medium(21−50),High(⩾50)

Отсортируйте полученный результат по количеству чеков (sales_count) по убыванию.
