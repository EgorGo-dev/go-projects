Необходимо определить, какие фильмы формируют основной спрос сервиса. Составьте запрос, который выведет список фильмов, отсортированных по популярности.

В результате должны быть поля:

title — название фильма;
rentals_count — количество аренд данного фильма (общее число записей аренды для него).
Возьмите в результат только 10 самых популярных фильмов.

Формат ввода
Для выполнения задач этого step'а необходимо воспользоваться сборкой базы данных sakila.sqlite.

Описание базы данных, схема связей, особенности хранения данных в таблице и ссылка на скачивание базы данных можно найти в теоретическом текстовом блоке step 1 level 6 БД для финальных задач "Sakila".

При выполнении практических заданий необходимо загрузить файл базы данных в любую удобную среду разработки (в курсе рассматривается SQLite) для написания SQL-запросов и работать с ней.

Отправленные запросы в этой и последующих задачах этого step'а будут тестироваться на этой же сборке базы данных, но для понимания формата данных в ответном запросе будем приводить его небольшую часть (полный ответ на запрос не будем доступен, поскольку в продуктовых задачах нет ответа "заранее").

Пример формата вывода требуемого запроса (тестирующая система преобразует вывод запроса в формат TABLE):
