Компания анализирует финансовую динамику. Необходимо рассчитать месячную выручку и изменение по сравнению с предыдущим месяцем.

В результате должны быть поля:

month — год и месяц платежа в формате YYYY-MM (год-месяц);
total_revenue — суммарная выручка за данный месяц;
growth — изменение выручки по сравнению с предыдущим месяцем (разница между текущей и предыдущей суммой).
Отсортируйте результат в хронологическом порядке.

Формат вывода
Пример формата вывода требуемого запроса (тестирующая система преобразует вывод запроса в формат TABLE):

+---------+---------------+-----------+
|  month  | total_revenue |  growth   |
+---------+---------------+-----------+
| 2005-05 | 4824.43       |           |
| 2005-06 | 9631.88       | 4807.45   |
| 2005-07 | 28373.89      | 18742.01  |
...
Примечания
Для того, чтобы привести значение даты в SQLite к запрошенному формату, можно воспользоваться функцией strftime(<format>, <column>) в SQLite (её аналог вам может быть известен из модуля Python datetime). При этом формат вывода даты описывается специальным регулярным выражением.

Пример работы функции по требуемому формату с нужным полем:

strftime('%Y-%m', payment_date)
