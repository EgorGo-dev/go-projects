задача из Яндекс LMS - Яндекс Лицея |SQL|

Найдите бонусные операции tx_type по данным из таблицы loyalty_point_transactions, в комментариях которых:

есть символ #,
или слово баллов,
или слово награду.
Для каждого типа операции выведите количество таких записей (tx_count).

Отсортируйте полученный результат по убыванию найденного количества.

Формат вывода
Корректный вывод для тестовой сборки (тестирующая система преобразует вывод запроса в формат TABLE):

+---------+----------+
| tx_type | tx_count |
+---------+----------+
| ADJUST  | 29       |
| EXPIRE  | 12       |
| SPEND   | 1        |
+---------+----------+
