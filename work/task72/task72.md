задача из Яндекс LMS - Яндекс Лицея |SQL|

Для каждой продажи выведите её метрику отклонения от цены среднего чека по клиенту:

customer_id — идентификатор клиента;

sale_id — идентификатор продажи;

sale_amount — сумму продажи, округлённую до 2-х знаков;

avg_amount_per_customer — средний чек клиента, округлённую до 2-х знаков;

diff_from_avg — отклонение текущей продажи от среднего чека клиента (разность между этими полями), округлённое до 2-х знаков.

Отсортируйте полученный результат сначала по полю customer_id, затем по полю sale_amount по убыванию.
