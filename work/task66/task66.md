задача из Яндекс LMS - Яндекс Лицея |SQL|

Постройте отчёт по использованию клиентами программы лояльности на основе накопляемых и списываемых баллов.

Выведите следующие поля:

customer_name
tier_name — уровень лояльности
total_earned_points — сумма начисленных баллов (EARN)
total_spent_points — сумма списанных баллов (SPEND)
Используйте данные из таблиц loyalty_point_transactions, loyalty_accounts, customers, loyalty_tiers.

Учитывайте только транзакции типов EARN и SPEND. Отсортируйте результат по полю total_earned_points по убыванию. При совпадении total_earned_points отсортируйте строки по идентификатору клиента customer_id по возрастанию. Поле customer_id выводить не нужно.

Формат вывода
Корректный вывод для тестовой сборки (тестирующая система преобразует вывод запроса в формат TABLE):

|           customer_name           | tier_name | total_earned_points | total_spent_points |

| Шашкова Ксения Егоровна           | Бронза    | 135                 | 130                |
| Исаев Изяслав Елизарович          | Бронза    | 66                  | 0                  |
| Рыбаков Януарий Бориславович      | Бронза    | 60                  | 0                  |
| Мартынов Алексей Терентьевич      | Бронза    | 58                  | 0                  |
| Симонова Евпраксия Константиновна | Бронза    | 52                  | 0                  |
| Вишняков Аггей Бенедиктович       | Бронза    | 51                  | 0                  |
...
Вывод для тестового запроса приведён не полностью из-за величины его размера.
