Для анализа программы лояльности необходимо понять, какие типы операций вообще встречаются, и как они работают.

Для таблицы loyalty_point_transactions определите уникальные профили операций в формате tx_type:points_delta. Для каждого профиля выведите абсолютное значение изменения баллов, после чего отсортируйте результат по абсолютному значению по убыванию, затем по профилю по возрастанию. Выведите в ответе первые 25 строк.

Примечания
Под абсолютным значением в данной задаче понимается функция модуля числа. В SQL для значений данного столба его можно посчитать при помощи функции ABS(<имя столбца, содержащего числовые данные>).
