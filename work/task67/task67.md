задача из Яндекс LMS - Яндекс Лицея |SQL|

Выведите магазины по таблице stores, у которых количество продаж выше среднего количества продаж по всем магазинам.

Выведите запросом следующие поля:

store_id;
sales_count — количество чеков.
Формат вывода
Корректный вывод для тестовой сборки (тестирующая система преобразует вывод запроса в формат CSV):

store_id,sales_count
1,13
5,13
10,13
11,17
14,15
15,13
17,14
19,15
21,13
22,16
24,15
Примечания
Эта задача поначалу кажется похожей на первую, но нюанс кроется в использовании агрегата для поиска количества продаж.
