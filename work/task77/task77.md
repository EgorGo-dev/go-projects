задача из Яндекс LMS - Яндекс Лицея |SQL|

Для каждой продажи необходимо вывести следующие поля:

customer_id — идентификатор клиента;
sale_id — идентификатор продажи;
sale_datetime — дата и время продажи;
purchase_number — порядковый номер покупки клиента (по дате).
Нумерация должна начинаться заново для каждого клиента.

Отсортруйте итоговый результат по полю customer_id, затем по полю sale_datetime.

Примечания
При вычислении поля days_to_next_purchase вам может понадобиться полезная функция SQLite JULIANDAY(...), которая преобразует текстовое значение даты в нужный объект, по которому можно найти разницу дат (JULIANDAY(date_1) - JULIANDAY(date_2)). В эту функцию можно оборачивать как значения столбцов (передавая имя поля), так и агрегатные/оконные функции. Подробнее о работе с ней можно почитать по ссылке.
