задача из Яндекс LMS - Яндекс Лицея |SQL|

Найдите для каждого клиента его самую крупную покупку.

Выведите запросом поля:

customer_id;
sale_id;
sale_amount с округлением до 2-х знаков;
rank_within_customer — рейтинг покупки по сумме;
оставить только самые крупные покупки (с рейтингом, равным 1).
Если несколько покупок с одинаковой максимальной суммой, присвойте им одинаковое место в рейтинге.
