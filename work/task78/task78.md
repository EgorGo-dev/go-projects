Для каждого товара определите его позицию по цене внутри категории.

Выведите поля:

product_id;
category_id;
base_price;
dense_price_rank — место рейтинга по убыванию цены внутри категории.
Пропусков в рейтинге быть не должно.

Отсортируйте результат по полю category_id, затем по полю dense_price_rank.
