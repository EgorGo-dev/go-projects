Размялись? Теперь вас ждут немного задач посложнее.

Когда способов оплаты становится много, полезно смотреть на них не только как на список, но и анализировать их свойства и преобразовывать информацию, например, составить удобночитаемую подпись. Средствами SQL можно в этом плане можно сделать нечто большее, чем кажется первоначально.

Для таблицы payment_methods выведите код и название способа оплаты, длину кода и строковую метку вида CODE - Name. Отсортируйте результат по длине кода по убыванию, затем по коду по возрастанию.

Формат вывода
Корректный вывод для тестовой сборки (тестирующая система преобразует вывод запроса в формат CSV):

method_code,method_name,code_len,label
paypass,"Бесконтактная оплата",7,"paypass - Бесконтактная оплата"
mirpay,"Mir Pay",6,"mirpay - Mir Pay"
card,"Банковская карта",4,"card - Банковская карта"
cash,"Наличные",4,"cash - Наличные"
sbp,"СБП",3,"sbp - СБП"
Примечания
Для того, чтобы сделать необходимую надпись, можно использовать оператор склейки строк ||.
Пример работы оператора: 'A' || ' - ' || 'B' == 'A - B'.

Для вычисления длины строки в данном столбце SQL можно использовать функцию LENGTH(column_name). Это вы ещё посмотрите в следующих уроках.
