В этой задаче вам понадобятся два CTE: для агрегирования данных и вычисления среднего значения выручки по магазинам.

Определите магазины, у которых суммарная выручка выше средней по всем магазинам.

Выведите поля:

store_id — идентификатор магазина;

store_name — название магазина;

total_revenue — суммарная выручка магазина 
(вычисляемая по формуле sum(unit_price×quantity−discount_amount)), округлённая до целого значения.
