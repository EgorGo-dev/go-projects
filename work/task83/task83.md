Для каждого фильма из таблицы film необходимо посчитать количество его аренд и определить его рейтинг по популярности среди фильмов, выпущенных в том же году.

Выведите:

title — название фильма;

release_year — год выпуска;

rentals_count — количество аренд фильма;

rank_in_year — позиция фильма по убыванию количества аренд внутри своего года выпуска.

В результат включите только фильмы, у которых ранг в своём году не выше 3 (то есть топ-3 по арендам для каждого года).

Отсортируйте результат по году выпуска по возрастанию, затем по рангу.

Формат вывода

text
+-----------------+--------------+---------------+--------------+
| title           | release_year | rentals_count | rank_in_year |
+-----------------+--------------+---------------+--------------+
| FILM A          | 2005         | 28            | 1            |
| FILM B          | 2005         | 25            | 2            |
| FILM C          | 2005         | 22            | 3            |
| FILM D          | 2006         | 30            | 1            |
| ...             |              |               |              |
+-----------------+--------------+---------------+--------------+
