Для каждого клиента необходимо определить степень изменения суммы покупки относительно предыдущей.

Выведите запросом следующие поля:

customer_id
sale_id
sale_amount - сумма продажи по каждой позиции данной покупки
previous_sale_amount - сумма продажи по каждой позиции предыдущей покупки (если данные о ней есть в таблице)
change_from_previous - изменение цены продажи
Сравнение должно происходить внутри клиента по дате покупки. Все вещественные значения необходимо итогово округлить до 2-х знаков после запятой.

Отсортируйте результат по полю customer_id, затем по полю sale_datetime.
